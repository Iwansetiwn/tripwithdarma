# Cara memperbarui website Anda

**Website:** https://tripwithdarma.my.id · **Editor:** https://app.pagescms.org
Bisa dari laptop atau browser HP. Setiap perubahan tampil di website sekitar 2 menit setelah Anda menekan **Save**.

## Masuk (login)
1. Buka **app.pagescms.org** → **Sign in with GitHub** (username dan password Anda).
2. Pilih **tripwithdarma**. Di sebelah kiri ada: *Hikes / Tours, Blog / Guides, Reviews, FAQ, About Ketut, Site settings & contact*.

## Mengubah harga atau detail trekking
1. **Hikes / Tours** → klik trekking yang ingin diubah.
2. Ubah **Price** (angka saja, contoh `450000`). Kosongkan jika ingin menampilkan "Price on WhatsApp".
3. Perbarui durasi, tingkat kesulitan, yang termasuk / tidak termasuk, dan jadwal (itinerary) → **Save**.

## Menambah trekking baru
**Hikes / Tours** → tombol **Add** → isi minimal *Hike name, Card summary, Duration, Difficulty, Google description* → **Save**.
Untuk menyembunyikan trekking tanpa menghapusnya, aktifkan **Hidden (draft)**.

## Menambah atau mengganti foto
1. Buka trekking (atau *About Ketut*, atau *Site settings → Homepage* untuk foto besar di atas).
2. Klik kolom foto → **Upload** → pilih foto. Gunakan foto dengan lebar minimal **1600 px**; website otomatis membuatnya kecil dan cepat.
3. Selalu isi **deskripsi foto** dalam bahasa Inggris (apa yang ada di foto, contoh "Morning mist over Lake Tamblingan"). Google membaca deskripsi ini.

## Menambah ulasan (hanya ulasan asli)
1. Buka ulasan di Tripadvisor.
2. **Reviews** → tombol **Add** → salin **nama**, **tanggal**, **isi ulasan** (boleh dipersingkat dengan "…", tapi jangan mengubah maknanya) dan tempel **link** ulasan.
3. Perbarui **rating** dan **jumlah ulasan** di bagian atas → **Save**.
Jangan pernah menulis ulasan sendiri atau meminta teman menulisnya.

## Menulis artikel blog
**Blog / Guides** → buka draft (ada 8 draft dengan judul bagian) atau tombol **Add** → tulis di bawah setiap judul (dalam bahasa Inggris) → tambahkan foto sampul dan deskripsinya → matikan **Hidden (draft)** → **Save**.

## Mengubah nomor WhatsApp, alamat, atau link
**Site settings & contact**. Nomor WhatsApp = angka saja dengan kode negara: `6281234567890`.
Alamat harus sama persis dengan di Google Maps dan Tripadvisor.

## Jika ada masalah
- Tidak ada yang hilang: setiap penyimpanan tersimpan sebagai versi. Minta bantuan web helper Anda untuk mengembalikan versi sebelumnya.
- Jika gagal menyimpan, pastikan kolom wajib (bertanda *) sudah diisi.
